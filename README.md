# sfml-bomber

Bomber is a simple arcade game where you shoot enemy tanks using rockets fired from a jet.
The game is built using C++ and SFML 2.6.

# Gameplay

For every tank you destroy, you earn 100 points. Try to get the highest score possible.

# Controls

- SPACE: Shoot a missile
- ESC: Exit the game
